Sure! Here are **10 beginner-friendly programming problems** similar to Fibonacci, Pascal's Triangle, odd/even, etc. These are good for practicing **loops, conditions, arrays, and basic logic**.
🟢 Beginner Programming Problems

1. **Odd or Even**

   * Input a number and determine whether it is odd or even.
   * Example: `7 → Odd`

2. **Fibonacci Series**

   * Print the first `N` Fibonacci numbers.
   * Example: `N = 7 → 0 1 1 2 3 5 8`

3. **Factorial**

   * Find the factorial of a number.
   * Example: `5 → 120`

4. **Prime Number Check**

   * Determine whether a number is prime.
   * Example: `17 → Prime`
   * Example: `15 → Not Prime`

5. **Reverse a Number**

   * Reverse the digits of a number.
   * Example: `12345 → 54321`

6. **Palindrome Number**

   * Check whether a number reads the same forward and backward.
   * Example: `121 → Palindrome`
   * Example: `123 → Not Palindrome`

7. **Multiplication Table**

   * Print the multiplication table of a given number.
   * Example: `5`

   ```text
   5 × 1 = 5
   5 × 2 = 10
   ...
   5 × 10 = 50
   ```

8. **Sum of Digits**

   * Find the sum of all digits of a number.
   * Example: `12345 → 15`

9. **Pascal's Triangle**

   * Print Pascal's Triangle for `N` rows.
   * Example for `5` rows:

   ```text
       1
      1 1
     1 2 1
    1 3 3 1
   1 4 6 4 1
   ```

10. **Armstrong Number**

* Check whether a number is an Armstrong number.
* Example: `153`
* `1³ + 5³ + 3³ = 153`
* Therefore, `153 → Armstrong Number`

If you're learning programming from the beginning, solve them in this order:

**Odd/Even → Multiplication Table → Sum of Digits → Factorial → Reverse Number → Palindrome → Prime → Fibonacci → Armstrong → Pascal's Triangle**

After these, you can move to **arrays, strings, sorting, searching, recursion, and pattern problems**.
